# authentification

pnpm add @nestjs/jwt @nestjs/passport passport passport-jwt
pnpm add -D @types/passport-jwt

| Package             | Rôle               |
| ------------------- | ------------------ |
| @nestjs/jwt         | générer token      |
| passport            | moteur auth        |
| @nestjs/passport    | intégration NestJS |
| passport-jwt        | stratégie JWT      |
| @types/passport-jwt | types TS           |
